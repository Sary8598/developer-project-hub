Developer Project Hub - Step 9: Development & Testing

1. Back up your current folder and export JSON before switching versions.
2. Extract this ZIP and open the developer-project-hub folder in VS Code.
3. Use Live Server with the same hostname and port as before.
4. Open a project > 9. Development & Testing.
5. Create a task, move it to Done using Edit, and verify the progress indicator.
6. Add a test case, a bug and a milestone. Reload and verify they persist.

This release adds js/development.js, updates js/app.js and index.html, and extends CSS/style.css.
Progress reflects completed development tasks only (not overall project completion).
JSON export includes the new project fields; existing file attachments remain outside JSON backups.
