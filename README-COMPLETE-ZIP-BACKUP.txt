DEVELOPER PROJECT HUB - COMPLETE ZIP BACKUP

New buttons: Export Complete ZIP / Import Complete ZIP.
The ZIP contains manifest.json (projects and planning data) and attachments/*.bin (images and PDF documents from IndexedDB).
Works offline, without external libraries. ZIP uses uncompressed entries, so file sizes may be large.

IMPORTANT:
- Keep your existing JSON backup and a copy of the original app before switching versions.
- Open using the same Live Server origin (host and port). IndexedDB is tied to the origin.
- Imports only NEW project IDs. Existing projects and their attachments are NOT overwritten or merged.
- Import is transactional across projects and files. If it fails, no partial import is committed.
- 250 MB ZIP size and 1000 ZIP entry limits.
- Only ZIP backups generated by this version are supported; generic compressed ZIP archives cannot be imported.
- Do not clear browser site data. Verify backups by restoring them on a separate browser profile/origin before relying on them.
