Developer Project Hub - Data Storage

1. Keep a backup of your current project folder and your JSON data export.
2. Unzip this folder and open it in VS Code.
3. Use the same Live Server origin (hostname and port) as before to access your existing IndexedDB projects.
4. Open a project > 5. Data Storage, choose a technology, complete notes, and save.
5. Reload to verify persistence.

This module documents a choice; it does not provision a database.
